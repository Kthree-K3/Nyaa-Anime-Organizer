# Nyaa Anime Organizer

A lightweight, modern web aggregator for Nyaa.si that automatically groups releases into organized folders and integrates with AniList for a smarter anime tracking experience.

### 🔗 [Live Demo](https://kthree-k3.github.io/Nyaa-Anime-Organizer/)

## ✨ Key Features

*   **Smart Grouping:** Automatically merges different releases and sub-groups of the same anime into clean, organized folders.
*   **AniList Integration:** Fetch rich metadata including cover art, banners, studios, and related sequels/prequels directly from AniList via GraphQL.
*   **Smart Watchlist:** Create a personalized list of anime to track. The scanner automatically filters results to show only what you're looking for.
*   **Keyword Manager:** Full control over search terms for each anime. Supports multiple keywords (aliases) per title and line-by-line editing to ensure 100% matching accuracy.
*   **Dynamic Filtering:** Flexible time range filtering (from 24h and Daily up to the last 7 days) and quality-based filtering (1080p, 720p, 480p).
*   **Advanced Sorting:** Dual-direction sorting (ASC/DESC) within folders by **Date, Size, or Name**.
*   **Quick Actions:** Integrated one-click search for **Nyaa, Google, and AniList** icons in every anime header.
*   **Data Portability:** Backup and transfer your watchlist and keywords between different environments using the **Export/Import (JSON Download/Upload)** feature.
*   **Modern Responsive UI:** Optimized Dark Mode design with sticky controls, auto-save editing, and an interactive "Anime Info" popover.
